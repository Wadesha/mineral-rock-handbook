矿床与产地

东海水晶 Donghai, Jiangsu江苏省连云港市东海县，中国东海水晶博物馆在县城西双湖畔，中国东海水晶城在中华北路，另有民办的圣时水晶博物馆设在国际水晶珠宝城内。这里能看到石英（水晶）、金红石（发晶、钛晶）、蛇纹石、蓝晶石、蛭石。博物馆与市场上最主要的品种。

昌乐蓝宝石 Changle, Shandong山东省潍坊市昌乐县，原生矿在五图街道的方山、方山北麓与邱家河一带，砂矿散布在县境与潍坊城区。中国蓝宝石博物馆在县城的中国宝石城内，乔官镇还有远古火山口群。这里能看到刚玉（蓝宝石）、红宝石与星光蓝宝石、二辉岩与纯橄榄岩包体。分原生与砂矿两类。

蒙阴金刚石 Mengyin, Shandong山东省临沂市蒙阴县联城乡常马庄，沂蒙钻石国家矿山公园依托原蒙阴金刚石矿（建材七〇一矿）建成，东北距蒙阴县城不远，有公路直达。这里能看到金刚石、金伯利岩、镁铝榴石、铬透辉石。产在金伯利岩里，是国内少见的金刚石原生矿。

可可托海三号矿脉 Koktokay, Xinjiang新疆维吾尔自治区阿勒泰地区富蕴县可可托海镇，可可托海国家矿山公园在镇上，核心是三号矿脉，另有地质陈列馆与阿依果孜矿洞。这里能看到绿柱石（海蓝宝石）、电气石（碧玺）、锂辉石、钽铌铁矿、锡石、白云母、石英、长石、黄玉（托帕石）、石榴子石、额尔齐斯石。伟晶岩里最有名的品种之一，呈六方柱状，蓝绿色到海蓝色，透明到半透明。

武义萤石 Wuyi, Zhejiang浙江省金华市武义县，武义萤石博物馆在县城的温泉小镇一带，杨家、后树等老矿区在县城周边。这里能看到萤石、石英（玉髓、蛋白石）、方解石、重晶石、黄铁矿、磷灰石、高岭土、玛瑙、黄蜡石。这个地点绝对的主角。

阳春孔雀石 Yangchun, Guangdong广东省阳江市阳春市马水镇石菉圩一带的石菉铜矿，市区有奇石街与阳春市博物馆，省博物馆也收藏有阳春产的孔雀石标本。这里能看到孔雀石、蓝铜矿、黄铜矿与黄铁矿、赤铜矿、硅孔雀石、褐铁矿、方解石、黄蜡石与青石。含铜硫化物在氧化带风化后的次生产物。

大冶铜绿山 Daye, Hubei湖北省黄石市大冶市金湖街道，铜绿山古铜矿遗址博物馆与铜绿山国家考古遗址公园在城西南不远处。这里能看到孔雀石、赤铜矿与自然铜、蓝铜矿、黄铜矿、黄铁矿、磁铁矿、赤铁矿、褐铁矿、高岭土。这个地点名字的由来。

应城石膏 Yingcheng, Hubei湖北省孝感市应城市城北街道团山一带，应城国家矿山公园与园内的中国石膏博物馆在团山北麓、凤尾湖畔。这里能看到石膏、硬石膏、泥质石膏、钙芒硝、岩盐、萤石、天青石、白云石、方解石、高岭石。这里的主角，以白色纤维石膏为主。

景德镇高岭 Gaoling, Jiangxi江西省景德镇市浮梁县瑶里镇高岭村，高岭国家矿山公园以高岭瓷土矿遗址为核心。这里能看到高岭石、埃洛石、伊利石、石英、云母、长石。近地表矿石的主要矿物，晶形不完整、呈碎片状，是长石在风化作用下分解的产物。

察尔汗盐湖 Qarhan, Qinghai青海省海西蒙古族藏族自治州格尔木市察尔汗镇，梦幻盐湖景区有游客服务中心，盐湖博物馆在厂区内，另有察尔汗盐湖国家矿山公园。这里能看到石盐（岩盐）、光卤石、钾石盐、水氯镁石、石膏、芒硝、白钠镁矾、软钾镁矾、钾盐镁矾、杂卤石、盐花与盐钟乳。干盐滩上那层坚硬盐盖的主体。

白云鄂博 Bayan Obo, Inner Mongolia内蒙古自治区包头市白云鄂博矿区，矿山路街道一带；白云鄂博矿山公园由主矿、东矿南部的废弃采坑治理改建而成，分主矿、东矿、西矿三个矿区。这里能看到磁铁矿与赤铁矿、氟碳铈矿与独居石、易解石与铌铁矿、萤石、霓石、钠闪石、金云母、黑云母、钠长石、白云石、方解石、磷灰石、重晶石。铁矿石的矿石矿物。

郴州柿竹园 Shizhuyuan, Hunan湖南省郴州市苏仙区白露塘镇，柿竹园国家矿山公园在山河路与柿竹园路交叉口一带；公园博物馆在苏仙区金鑫路，另有郴州世界有色金属博物馆在郴州大道与林邑路交汇处。这里能看到白钨矿与黑钨矿、辉铋矿与辉钼矿、锡石、绿柱石与电气石、石榴子石、透辉石、硅灰石、符山石、萤石。钨的两种主要矿石矿物。

大麻坪橄榄石 Damaping, Hebei河北省张家口市万全区北新屯乡大麻坪村西，有三级公路从村东通过。附近的崇礼接沙坝一带也有同类露头。这里能看到橄榄石（贵橄榄石）、辉石、石榴石、尖晶石、玄武岩与石柱群。产在第三纪汉诺坝玄武岩底部的橄榄岩包体里。

宣化赤铁矿 Xuanhua, Hebei河北省张家口市宣化区庞家堡镇，原龙烟铁矿矿区（红石山）一带，现存废弃矿坑、近北庄露天采场、旧厂房与马万水纪念馆。这里能看到赤铁矿、镜铁矿、菱铁矿、褐铁矿与磁铁矿、石英、方解石、黄铁矿、绿泥石、磷灰石。宣龙式铁矿的主角，有两种最醒目的形态。

岩石露头

五大连池玄武岩 Wudalianchi, Heilongjiang黑龙江省黑河市五大连池市，老黑山与火烧山景区在核心区，龙门石寨在另一侧，两山之间的石海连绵成片。五大连池世界地质公园博物馆在药泉西路。这里能看到碱性玄武岩、橄榄石与地幔包体、结壳熔岩、翻花熔岩与块状熔岩、气孔与杏仁体、浮岩、火山弹与集块岩。这里喷出的不是普通玄武岩，而是富钾的碱性玄武岩，包括白榴玄武岩、白榴歪长玄武岩与玻基辉橄玄武岩等。

雁荡山流纹岩 Yandangshan, Zhejiang浙江省温州市雁荡山，灵峰、灵岩、大龙湫、方洞等分景区都有溢流相剖面，朝阳嶂与五峰山的露头最适合贴近观察，雁荡山博物馆内有世界火山岩展厅。这里能看到流纹岩与球泡流纹岩、球泡与石泡、熔结凝灰岩与凝灰岩、石英正长斑岩、柱状节理。这里的主体岩石。

黄山花岗岩 Huangshan, Anhui安徽省黄山市黄山风景区，云谷寺谷地、光明顶、玉屏楼至天都峰、西海大峡谷与飞来石一带都能走到岩石跟前。这里能看到花岗岩、石英、钾长石与斜长石、铁白云母（黑云母）、锆石与磷灰石。黄山的主体是一个复式岩体，由早期的太平花岗闪长岩与后来的黄山花岗岩组成，后者又分四期，从粗粒似斑状到中细粒斑状都有。

泰山片麻岩 Taishan, Shandong山东省泰安市泰山，红门至中天门登山道沿线、中天门、南天门、桃花峪彩石溪都能看到露头；泰山地质公园博物馆在岱庙北侧。这里能看到黑云斜长片麻岩与斜长角闪岩、混合岩与混合花岗岩、石英、钾长石与斜长石、黑云母与角闪石、石榴子石、二长花岗岩与石英闪长岩。泰山岩群的表壳岩，是这一带最古老的岩石。

济南辉长岩 Jinan, Shandong山东省济南市，卧牛山地质公园在历城区华山街道，药山公园在天桥区无影山北路，华山历史文化湿地公园在历城区荷花路。这几处都是岩体出露的孤立山头。这里能看到辉长岩、斜长石、单斜辉石、橄榄石、黑云母、角闪石、磁铁矿、磷灰石、大理岩与矽卡岩。商品名济南青，是这里的主角。

房山汉白玉 Fangshan, Beijing北京市房山区大石窝镇高庄村西的大白玉塘采石场遗址，中国房山世界地质公园博物馆在长沟镇六甲房村。这里能看到汉白玉、白云石大理岩与青白石、方解石型大理岩、硅灰石、滑石、透闪石、透辉石、艾叶青与螺丝转。一种质地极细的白色大理岩。

大别山榴辉岩 Dabieshan, Anhui安徽省安庆市岳西县菖蒲镇水畈村碧溪岭，榴辉岩出露在乡村公路边坡与河床；同区还有潜山市水吼镇新店的含金刚石榴辉岩、牌楼至菖蒲的硬玉石英岩带，以及韩长冲大理岩中的榴辉岩。这里能看到榴辉岩、石榴子石、绿辉石、金红石、柯石英与金刚石、蓝晶石、多硅白云母、角闪石、绿帘石、硬玉石英岩与大理岩。这个地点的主角，外观上最醒目的特征是红绿相间。

桂林洞穴方解石 Guilin, Guangxi广西壮族自治区桂林市，芦笛岩在秀峰区芦笛路光明山南麓，七星岩在七星区七星景区内的普陀山腹。这里能看到方解石、钟乳石、石笋、石柱与石幔、穴盾与流石坝、石花与石旗。所有洞穴沉积物的唯一主角。

这里写的是能走到跟前去看的东西，以及它们为什么长成这样。每一处的位置、矿种、共生关系与开放状态，都对照了公开资料并注明来源。实地情况会随季节、开放安排与保护规定变化，出发前请再确认一次当下的情形；文中标出的地点是观察对象所在的大致范围，不代表那里可以随意采集标本，也不代表进入不受限制。
